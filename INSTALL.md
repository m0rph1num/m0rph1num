# Установка

1. Открой публичный репозиторий `m0rph1num/m0rph1num`.
2. Замени `README.md` и папку `assets` файлами из комплекта.
3. Убедись, что файл находится в корне ветки по умолчанию.
4. Открой https://github.com/m0rph1num.

В SVG нет внешних шрифтов и иллюстрация справа удалена. Заголовки переведены в кривые, светлая и тёмная темы доступны автоматически. PNG в каталоге `previews` нужны только для проверки, публиковать их необязательно.
